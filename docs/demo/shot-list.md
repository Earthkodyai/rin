# วิดีโอเดโม (9.2): shot list

เป้าหมาย: 60–90 วินาที เห็นทั้งเช้า (ทัก → เกม → ชม → ประโยคปิด) ครบ 3 เกม และหน้าที่ไม่กดดัน (วันพัก/วันป่วย, No pouting, ความเป็นส่วนตัว) · Claude ตัดต่อด้วย ffmpeg ใส่การ์ดเปิด/ปิด แล้วทำ GIF สั้นให้ README · วิดีโอเต็มขึ้น GitHub Release v0.1.0

## เตรียมเครื่อง (ครั้งเดียว)
1. Control Center → **Screen recorder** → ตั้งค่า: เสียง = **System sounds** (เสียงในเครื่องเท่านั้น ไม่ใช่ไมค์ เสียงรินจะติด เสียงคุณไม่ติด), ความละเอียด 1080p, 30 fps
2. เปิดเสียงปลุก (alarm volume) ให้ได้ยินชัด และปิดเสียงแจ้งเตือนของแอปอื่น หรือเช็กว่าไม่มี notification ส่วนตัวขึ้นแถบบนตอนอัด
3. **อย่าเปิด Do Not Disturb แบบ Total silence** (จะปิดเสียงปลุกด้วย)
4. ตั้งปลุกครั้งเดียว 3 อัน ห่างกัน 3 นาที ชื่อ "Demo": เกม **Colour pads** (เวลา T), **Cup shuffle** (T+3), **Repeat after Rin** (T+6)

## คลิปที่อัด (อัดเป็นคลิปแยก หรือคลิปยาวคลิปเดียวก็ได้ Claude ตัดช่วงรอออกเอง)
| # | ฉาก | ทำอะไร | ยาวในวิดีโอ |
|---|---|---|---|
| A | หน้าหลัก | เปิดแอป รินโบกมือทัก แล้ว **แตะหัวริน 1 ครั้ง** (มีบทพูด + ซับไตเติล) | ~8 วิ |
| B | ตั้งปลุก | กด + ตั้งปลุก "Demo" เลือกเกม แล้ว Save กลับมาหน้าหลักรินพูด "alarm saved" (ใช้ตอนตั้งปลุกอันแรกในข้อ 4) | ~8 วิ |
| C | ปลุก + Colour pads | ปล่อยให้ดัง รินทัก → **Let's play** → เล่น **ตั้งใจกดผิด 1 ครั้ง** ให้รินดุ → เล่นจนชนะ → คำชม + ประโยคปิด | ~30 วิ |
| D | ปลุก + Cup shuffle | Let's play → ดูโต๊ะ 3D และมือริน → เลือกถูก 3 ครั้ง → ชนะ | ~20 วิ |
| E | ปลุก + Repeat after Rin | Let's play → พูดประโยคตามริน (เสียงคุณไม่ติด แต่ซับและผลจะเห็น) → ชนะ | ~15 วิ |
| F | ตั้งค่า | แตะชิป **Rest day** ให้เห็นข้อความ แล้วแตะอีกครั้งเพื่อยกเลิก → เฟือง → **No pouting**, **About Rin**, เปิด **How Rin uses your data** เลื่อนนิดหน่อย | ~10 วิ |

ไม่ต้องสมบูรณ์แบบ ผิดพลาดแล้วอัดใหม่เฉพาะคลิปนั้นได้ อัดเสร็จบอก Claude แล้ว Claude ดึงไฟล์จากโทรศัพท์ด้วย adb (เฉพาะไฟล์อัดหน้าจอของวันนี้)
