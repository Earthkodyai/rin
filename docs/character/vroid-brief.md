# Brief ออกแบบริน (VRoid Studio) — สำหรับ task 2.3

> คุณออกแบบได้ตามจังหวะของคุณเอง ระหว่างนี้แอปใช้โมเดลตัวอย่างของ VRoid (อยู่ใน debug build บนมือถือคุณเท่านั้น) เมื่อโมเดลรินเสร็จ ให้วางไฟล์ `.vrm` ไว้นอก repo แล้วบอกใน session ของ task 2.3 เพื่อทำ pipeline (atlas, KTX2, วัดขนาด)
> บุคลิกและสไตล์การพูดอยู่ใน character sheet ของ task 2.3 (Claude ร่าง คุณแก้) brief นี้เป็นเรื่องหน้าตาและการ export เท่านั้น

## ตัวตน (ต้องมี)
- **ผู้ใหญ่ชัดเจน** (กฎเนื้อหาใน CLAUDE.md และ 05e): สัดส่วนผู้ใหญ่ (ใน VRoid ตั้ง Height ไม่ต่ำ และ Head size ไม่ใหญ่เกินตัว) หน้าไม่เป็นเด็ก ดวงตาไม่ใหญ่เกินจริงแบบตัวละครเด็ก
- **"เพื่อนตอนเช้า" ไม่ใช่แฟน** (01-decisions): ท่าทางสบายๆ เป็นกันเอง ไม่เน้นเสน่ห์ทางเพศ
- **ชุด:** ชุดนอนหรือชุดอยู่บ้านที่สุภาพ (เช่น เสื้อยืดตัวหลวม + กางเกงขายาว, ฮู้ดดี้, คาร์ดิแกน) ไม่มีส่วนโปร่ง ไม่สั้นหรือรัดรูป
- **เป็นตัวละคร original:** ไม่เลียนตัวละครที่มีเจ้าของ (ทรงผม + สีผม + ชุดที่รวมกันแล้วจำได้ว่าเป็นใคร) ใช้ preset ของ VRoid เป็นจุดเริ่มแล้วปรับให้เป็นของตัวเอง

## ข้อจำกัดทางเทคนิค (จาก S2 และ 05a)
| หัวข้อ | เป้า | เหตุผล |
|---|---|---|

| Texture | atlas ไม่เกิน 2048 px (ตั้งตอน export) | 30 texture แยกกันคือต้นทุนหลักของ GPU memory; task 2.3 จะแปลงเป็น KTX2 ต่อ |

## ขั้นตอน export (VRoid Studio 2.3.0)
1. Camera/Exposure → Export → **VRM 1.0**
2. Polygon reduction: เปิด (ผม/เสื้อผ้า ระดับกลาง)
3. Texture atlas: เปิด, resolution **2048** (ถ้าได้ขนาดไฟล์เกิน 15 MB ลอง 1024 สำหรับเสื้อผ้า)
4. Reduce materials: เปิด
5. **VRM meta / license** (สำคัญ เพราะแอปแจกจ่ายสาธารณะ แต่ไฟล์โมเดลต้องไม่ถูกเอาไปใช้ต่อ):
   - Author: ชื่อที่ใช้ใน GitHub ของคุณ
   - Avatar permission: **Only author**
   - Violent / sexual usage: **ไม่อนุญาต**
   - Commercial usage: **Personal non-profit** (สิทธิ์ของคุณในฐานะเจ้าของไม่ถูกจำกัดด้วย meta นี้)
   - Redistribution: **ไม่อนุญาต** · Modification: **ไม่อนุญาต**
6. เก็บไฟล์ `.vroid` (ต้นฉบับ) และ `.vrm` ไว้**นอก repo** (repo ignore `*.vrm` อยู่แล้ว) task 2.3 จะตัดสินว่าจะส่งโมเดลไปกับแอปอย่างไรโดยไม่เปิดไฟล์ดิบใน repo สาธารณะ
