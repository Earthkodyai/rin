## 2. กติกาการเขียน
- **รินพูดทางเดียว (D21):** ไม่มีบทที่รอให้ผู้ใช้ตอบ คำถามใช้ได้แค่แบบลอยๆ ที่ไม่ต้องตอบ ("Ready now?") ไมค์ใช้เฉพาะในเกม Repeat after Rin
- **อังกฤษล้วน** (คุณเลือก 2026-09-30) ระดับ A2–B1 ฟังออกตอนเพิ่งตื่น ตัวตรวจจะไม่ผ่านถ้ามีตัวอักษรไทย
- **สั้น:** ไม่เกิน 3 ประโยคสั้น, ไม่เกิน 12 คำต่อประโยค, ไม่เกิน 16 คำต่อบรรทัด (character sheet เขียน "1–2 ประโยค" แต่ตัวอย่างในนั้นเองและบทดุชุด A มีแบบ "Phew. You're up. That's what matters." จึงนับประโยคสั้นแบบนี้ได้ 3)
- น้ำเสียง **warm, calm, gently teasing** · เพื่อน ไม่ใช่แฟน · แซวสถานการณ์ (ผ้าห่ม หมอน) ไม่แซวตัวคน สำเนียง หรือภาษาอังกฤษ ฟังไม่ออกให้โทษหูตัวเอง
- **ไม่พูดชื่อผู้ใช้และไม่พูดเวลา** เพราะอัดเสียงไว้ล่วงหน้าไม่ได้ (ชื่อและเวลาแสดงบนจอได้) และไม่พูดจำนวนนาทีของ snooze เพราะตั้งได้หลายค่า
- รินซื่อตรงว่าเป็น AI: ไม่อ้างว่ากินได้ มองเห็นท้องฟ้า หรือมีชีวิตนอกแอป ("If I could eat, I'd pick basil pork…") และไม่ทำให้รู้สึกผิด (ตัวตรวจห้าม lonely / miss you / คำเรียกแฟน)
- **ประโยคปิด** (คุณเลือก 2026-09-30) ใช้ใน `after.remark` และ `after.meal.*`:
  - **ท้องฟ้า/อากาศ: ห้ามบอกว่าอากาศเป็นยังไง** (ฝนตก แดดออก ร้อน พระอาทิตย์ขึ้นแล้ว) เพราะรินรู้ไม่ได้ ใช้ได้แค่ประโยคที่จริงทุกสภาพอากาศหรือชวนให้ไปดูเอง ("Whatever the weather, you're up.")
  - **มื้ออาหาร: พูดถึงความสำคัญของมื้อถัดไปตามเวลาที่ปลุก** (เช้า 04–10, กลางวัน 11–15, เย็น 16–21, ดึก 22–03) ไม่เอ่ยชื่อเมนู ไม่อ้างผลทางสุขภาพเกินความรู้ทั่วไป
  - บวกเรื่องวันนี้และการนอน
- `~` แสดงบนจอเท่านั้น ไม่ส่งเข้า TTS · ถ้า TTS ต้องอ่านต่างจากบนจอ ใส่ `say` (เช่นตัวเลข)

## 3. รูปแบบไฟล์ (lines.json)
`id, pool, text, emotion, gesture, tag` + ถ้ามี: `say`, `src` (มาจาก strings.xml ตัวไหน), `topic` (ประโยคปิด)
- `id` เป็นจุดคั่น เช่น `ring.sleepy.03` **ห้ามเปลี่ยนหรือใช้ซ้ำหลัง 4.3** (ชื่อไฟล์เสียงและ log ผูกกับ id) ประโยคที่ตัดทิ้งให้ลบ id ทิ้งไปเลย ไม่เอา id เดิมไปใช้ใหม่
- `emotion` = ชื่อใน `moods.json` (sleepy, cheerful, proud, worried, pouty, sulky, relieved)
- `gesture` = ชื่อใน `gestures.json` หรือ `null` เป็นแค่คำแนะนำ ตอนแสดงแบบแถบหัวไหล่ ตัวเล่นจะเปลี่ยน `pout`→`huff`, `clap`→`joy` ตามรสนิยมที่คุณเลือกใน 2.5
- `tag` = แท็กเสียงของ `eleven_v3` หนึ่งตัวต่อบรรทัดหรือ `null` เลือกได้จากรายการ `tags` ในไฟล์เท่านั้น แท็กที่ถูกอ่านออกเสียงแทนการแสดงอารมณ์ให้จับตอน QA ใน 4.3 (S4 ยังไม่เจอ)

## 4. Pool และกติกาการเลือก (4.2 เป็นคนทำ)
| use | ความหมาย | ขั้นต่ำ |
|---|---|---|
| `daily` | ใช้ไม่เกินวันละครั้ง **ห้ามซ้ำภายใน 7 วัน** (เกณฑ์จบเฟส) | ≥ 7 บรรทัด (pool ที่มี `mix` นับรวมกับ pool ที่ผสม) |
| `session` | ใช้ได้หลายครั้งในเช้าเดียว ไม่ซ้ำกันในเช้านั้นจนกว่าจะวนครบ | — |
| `event` | เกิดไม่บ่อย (snooze, สาย, เปิดแอป) สุ่มแบบไม่ซ้ำครั้งก่อน | — |

**หนึ่งเช้า:** `ring.*` (หรือ `back.*` หลัง snooze) → `game.intro` / `game.intro.<เกม>` → บทในเกม (`pads.*`, `cups.*`, `speech.*`, `game.last`) → `won.clean` หรือ `won.hard` → ประโยคปิดหนึ่งประโยค สุ่มจาก `after.remark` รวมกับ `after.meal.<ช่วงเวลาที่ปลุก>` (จบด้วยการบอกลา) → จบ
- **snooze:** ครั้งแรก = `snooze.first`, ครั้งสุดท้ายที่เหลือตามเพดานในตัวแก้ปลุก = `snooze.last` (ถ้าเพดานเป็น 1 ใช้ `first`), ครั้งกลางๆ = `snooze.again` · ปลุกซ้ำหลังจากนั้นใช้ `back.*` ชุดเดียวกัน งอนจบทันทีเมื่อลุก (character sheet §5)
- **วันเสาร์–อาทิตย์** ใช้ `ring.dayoff` แทน sleepy/cheerful · ปลุกช้าใช้ `ring.late`
- ประโยคปิดข้ามได้ด้วยการแตะ/ออกจากหน้า และไม่ทำให้ปิดปลุกช้าลง (ปลุกหยุดตั้งแต่ชนะเกมแล้ว)
- **ไม่มีอะไรข้ามวัน (D22):** ไม่มี streak, Bond, "welcome back" หรือ "yesterday" · **ไม่เก็บประวัติประโยค:** ประโยค `daily` เลือกจากลำดับสุ่มคงที่ของ pool ตามวันที่ (แบบเดียวกับ Rin picks) pool ขนาด N จึงวนซ้ำทุก N วัน (≥ 7)
- **เฟส 5** (`p5.rest`, `p5.sick`) อยู่ในไฟล์แล้วแต่แอปยังไม่เล่นจนกว่าจะทำเฟส 5 · วันพักและวันป่วยตั้งจากหน้าตั้งค่า (เดิมจะรับจากคำตอบ "I feel sick" ซึ่งตัดไปแล้ว)
- **Crisis protocol:** เมื่อผู้ใช้พิมพ์หรือพูดอะไรเองไม่ได้ ก็ไม่มีทางตรวจเจอ จึงไม่มีบทเสียงสำหรับ crisis แล้ว สายด่วน 1323 จะอยู่เป็นข้อความคงที่ในแอปแทน (ตัดสินที่ไหนในเฟส 5/6, ADR 0003)
