## 2. กติกาการเขียน
- **อังกฤษล้วน** (คุณเลือก 2026-09-30) ระดับ A2–B1 ฟังออกตอนเพิ่งตื่น ตัวตรวจจะไม่ผ่านถ้ามีตัวอักษรไทย
- **สั้น:** ไม่เกิน 3 ประโยคสั้น, ไม่เกิน 12 คำต่อประโยค, ไม่เกิน 16 คำต่อบรรทัด (character sheet เขียน "1–2 ประโยค" แต่ตัวอย่างในนั้นเองและบทดุชุด A มีแบบ "Phew. You're up. That's what matters." จึงนับประโยคสั้นแบบนี้ได้ 3)
- น้ำเสียง **warm, calm, gently teasing** · เพื่อน ไม่ใช่แฟน · แซวสถานการณ์ (ผ้าห่ม หมอน) ไม่แซวตัวคน สำเนียง หรือภาษาอังกฤษ ฟังไม่ออกให้โทษหูตัวเอง
- **ไม่พูดชื่อผู้ใช้และไม่พูดเวลา** เพราะอัดเสียงไว้ล่วงหน้าไม่ได้ (ชื่อและเวลาแสดงบนจอได้) และไม่พูดจำนวนนาทีของ snooze เพราะตั้งได้หลายค่า
- คำถามใช้ได้จริงเฉพาะใน `chat.question` (มีปุ่มให้ตอบ) ที่อื่นใช้ได้แค่คำถามลอยๆ ที่ไม่ต้องตอบ ("Ready now?")
- รินซื่อตรงว่าเป็น AI: ไม่อ้างว่ากินได้ มองเห็นท้องฟ้า หรือมีชีวิตนอกแอป ("If I could eat, I'd pick chicken rice.") และไม่ทำให้รู้สึกผิด (ตัวตรวจห้าม lonely / miss you / คำเรียกแฟน)
- **เรื่องชวนคุย** (คุณเลือก 2026-09-30): ท้องฟ้าและอากาศ, อาหารเช้าแบบ**อาหารไทยตามสั่ง** เรียกเป็นคำอังกฤษ (basil pork with a fried egg, rice porridge, grilled pork and sticky rice, Thai omelette on rice, soy milk and fried dough sticks) ไม่ใช้ชื่อไทยทับศัพท์ เพราะเสียง Rin soft อ่านผิดได้ และ Vosk ต้องรู้จักคำบนปุ่ม · บวกเรื่องการนอนและแผนวันนี้
- `~` แสดงบนจอเท่านั้น ไม่ส่งเข้า TTS · ถ้า TTS ต้องอ่านต่างจากบนจอ ใส่ `say` (เช่น 1323 → "one, three, two, three")

## 3. รูปแบบไฟล์ (lines.json)
`id, pool, text, emotion, gesture, tag` + ถ้ามี: `say`, `src` (มาจาก strings.xml ตัวไหน), `topic`/`replies` (คำถาม), `reply_to`/`intent` (คำตอบ), `streak`
- `id` เป็นจุดคั่น เช่น `ring.sleepy.03` **ห้ามเปลี่ยนหรือใช้ซ้ำหลัง 4.3** (ชื่อไฟล์เสียงและ log ผูกกับ id) ประโยคที่ตัดทิ้งให้ลบ id ทิ้งไปเลย ไม่เอา id เดิมไปใช้ใหม่
- `emotion` = ชื่อใน `moods.json` (sleepy, cheerful, proud, worried, pouty, sulky, relieved)
- `gesture` = ชื่อใน `gestures.json` หรือ `null` เป็นแค่คำแนะนำ ตอนแสดงแบบแถบหัวไหล่ ตัวเล่นจะเปลี่ยน `pout`→`huff`, `clap`→`joy` ตามรสนิยมที่คุณเลือกใน 2.5
- `tag` = แท็กเสียงของ `eleven_v3` หนึ่งตัวต่อบรรทัดหรือ `null` เลือกได้จากรายการ `tags` ในไฟล์เท่านั้น แท็กที่ถูกอ่านออกเสียงแทนการแสดงอารมณ์ให้จับตอน QA ใน 4.3 (S4 ยังไม่เจอ)

## 4. Pool และกติกาการเลือก (4.2 เป็นคนทำ)
| use | ความหมาย | ขั้นต่ำ |
|---|---|---|
| `daily` | ใช้ไม่เกินวันละครั้ง **ห้ามซ้ำภายใน 7 วัน** (เกณฑ์จบเฟส) | ≥ 7 บรรทัด (pool ที่มี `mix` นับรวมกับ pool ที่ผสม) |
| `session` | ใช้ได้หลายครั้งในเช้าเดียว ไม่ซ้ำกันในเช้านั้นจนกว่าจะวนครบ | — |
| `event` | เกิดไม่บ่อย (snooze, สาย, เปิดแอป) สุ่มแบบไม่ซ้ำครั้งก่อน | — |
| `bound` | ผูกกับคำถาม (`reply_to`) | ครบ affirm + deny |
| `fixed` | เล่นตามลำดับเสมอ ไม่สุ่ม (crisis) | — |

**หนึ่งเช้า:** `ring.*` (หรือ `back.*` หลัง snooze) → `game.intro` / `game.intro.<เกม>` → บทในเกม (`pads.*`, `cups.*`, `speech.*`, `game.last`) → `won.clean` หรือ `won.hard` → คุย
- **snooze:** ครั้งแรก = `snooze.first`, ครั้งสุดท้ายที่เหลือตามเพดานในตัวแก้ปลุก = `snooze.last` (ถ้าเพดานเป็น 1 ใช้ `first`), ครั้งกลางๆ = `snooze.again` · ปลุกซ้ำหลังจากนั้นใช้ `back.*` ชุดเดียวกัน งอนจบทันทีเมื่อลุก (character sheet §5)
- **วันเสาร์–อาทิตย์** ใช้ `ring.dayoff` แทน sleepy/cheerful · ปลุกช้าใช้ `ring.late`
- **คุยหลังเกม (1–2 จังหวะ ข้ามได้เสมอ):** `chat.question` → ปุ่ม 4 ปุ่ม: คำตอบ ✅ / ❌ ของคำถามนั้น + "I'm tired" + "I feel sick" → ถ้ากด ✅/❌ ใช้ `chat.answer` ของคำถามนั้น, tired ใช้ `chat.tired`, sick ใช้ `chat.sick` (จบการคุย ไม่ถามต่อ) → คำถามที่ 2 (หัวข้ออื่น) หรือจบ → ปุ่มปิด "Thanks, Rin" (`chat.thanks`) หรือ `chat.bye` · ปุ่ม "Good morning, Rin" (`chat.greet`) มีเฉพาะจังหวะแรก · พูดแล้วไม่ตรงปุ่มใด = `chat.unknown` ครั้งเดียว แล้ว `chat.totap` (ใช้ปุ่มอย่างเดียว ตาม S3) · กดข้าม = `chat.skip` · รายละเอียดปุ่มสรุปใน 4.2
- **เฟส 5** (`p5.*`) อยู่ในไฟล์แล้วแต่แอปยังไม่เล่นจนกว่าจะทำเฟส 5 · `live.*` และ `safety.ai` สำหรับโหมดคุยสด (เฟส 7)
- **Crisis** (`safety.crisis`) เขียนตายตัว เล่น 01 แล้ว 02 พร้อมเบอร์ 1323 บนจอ หยุดเสียงปลุก เกม และการงอนทั้งหมด (05e) โหมดออฟไลน์ใช้ปุ่มตอบเท่านั้นจึงยังไม่มีทางเข้าถึง บทนี้เตรียมไว้ให้โหมดคุยสด
