# เฟส 4 — เสียงและบทสนทนาแบบออฟไลน์ (≈ 6–8 วัน)

> **ตาม D20 (2026-09-30)** · อ่านประกอบเมื่อจำเป็น: [05d-voice-dialogue.md](05d-voice-dialogue.md) · [character-sheet](../character/character-sheet.md) · [S3](../spikes/S3-offline-stt.md) · [S4](../spikes/S4-voice.md)

## เป้าหมาย
รินพูดภาษาอังกฤษด้วยเสียง "Rin soft" แบบออฟไลน์ทั้งหมด และผู้ใช้ตอบกลับเป็นภาษาอังกฤษได้ (พูดหรือแตะคำตอบบนจอ)

## ลำดับในหนึ่งเช้า (D20)
- ปลุกดัง → รินทักสั้นๆ (ประโยคเดียว เสียงปลุกหรี่ลงตอนพูด) → เล่นเกมตามเดิม → ปลุกหยุด
- บนหน้าฉลอง: คุย **1–2 จังหวะ** (รินถาม → ผู้ใช้ตอบด้วยคำตอบแนะนำบนจอ → รินตอบรับ) **ข้ามได้เสมอ** · การคุยไม่ทำให้ปิดปลุกช้าลง
- ring path เดิมไม่แตะ: เสียงรินเล่นผ่าน VoicePlayer นอก ring path ถ้าไฟล์เสียงหาย แสดงซับไตเติลแทน

## แผนงาน (task ละ 1 session)
- **4.1 Script bible + บท (~300 ประโยค, $0):** กติกาการเขียน (น้ำเสียง "warm, calm, gently teasing", SFW, ผู้ใหญ่, ความยาว), หมวดสถานการณ์ × อารมณ์ (ทัก, เชียร์ในเกม, ดุเบาๆ, ชม, snooze, ฉุกเฉิน, คุยหลังเกมตามเจตนา `affirm/deny/tired/sick/greet/thanks/unknown`), รูปแบบไฟล์ `id, text, emotion, gesture` · Claude ร่าง คุณตรวจ · นับตัวอักษรรวมให้พอ credit
- **4.2 คุยออฟไลน์ ($0):** STT แบบคำตอบแนะนำ (Vosk grammar = คำบนจอ ตาม S3, พูดหรือแตะ, ถามซ้ำ 1 ครั้งแล้วขึ้นปุ่ม) + ตัวจับเจตนา + ตัวเลือกประโยค (ไม่ซ้ำใน 7 วัน, ถ่วงตามอารมณ์) · แสดงเป็นซับไตเติลก่อนมีเสียง · unit test ทั้งหมด
- **4.3 เดือนที่จ่าย (~$6):** คุณซื้อ ElevenLabs Starter → ตรวจอัตรา credit ของ `eleven_v3` → สร้างเสียงทั้งหมด → ตัดเงียบ/ปรับความดัง (≈ −16 LUFS)/Opus → mouth track → QA (ฟังทุกประโยค สร้างใหม่ที่ผิด) → **รูปปากสระ (ค้างจาก 2.4):** คำพยางค์เดียว ~40 คำ (dev 20 / held-out 20 ล็อกก่อนวิเคราะห์) ผ่าน ≥ 60% ค่อยเปิด `shapes: true` ไม่ผ่านใช้ความดังต่อ → แพ็ก → คุณยกเลิก subscription
- **4.4 วัดจบเฟส ($0)**

## จบเฟสเมื่อ
- เปิดโหมดเครื่องบินแล้วใช้งานได้ครบทั้งเช้า (ทัก → เกม → คุยหลังเกม)
- ประโยคไม่ซ้ำภายใน 7 วัน (ทดสอบด้วยนาฬิกาจำลอง ไม่ต้องรอ 7 วันจริง)
- ปากตรงกับเสียง (ผู้ทดสอบดูด้วยตา + ค่าที่วัดได้ตาม 2.4)
