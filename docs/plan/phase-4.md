## ลำดับในหนึ่งเช้า (D20 → D21)
- ปลุกดัง → รินทักสั้นๆ (ประโยคเดียว เสียงปลุกหรี่ลงตอนพูด) → เล่นเกมตามเดิม → ปลุกหยุด
- บนหน้าฉลอง: รินชม (`won.*`) แล้วพูดประโยคปิดหนึ่งประโยค (`after.remark` / `after.meal.*`: วันนี้, ท้องฟ้าแบบไม่บอกสภาพอากาศ, ความสำคัญของมื้อตามเวลาที่ปลุก จบด้วยการบอกลา) **ไม่มีการถามตอบ** (D21 ตัดการคุย 1–2 จังหวะของ D20) แตะข้ามได้
- ring path เดิมไม่แตะ: เสียงรินเล่นผ่าน VoicePlayer นอก ring path ถ้าไฟล์เสียงหาย แสดงซับไตเติลแทน
