# เฟส 4 — เสียงและบทสนทนาแบบออฟไลน์ (≈ 6–8 วัน)

> อ่านประกอบเมื่อจำเป็น: [05d-voice-dialogue.md](05d-voice-dialogue.md)
- Script bible + 300–500 ประโยค (Claude ร่าง คุณตรวจ) และสคริปต์ pipeline ใน `tools/voice/` (บท → TTS → QA → viseme JSON → แพ็ก)
- **รูปปากสระ (ค้างจาก 2.4):** ในเดือนที่จ่าย ElevenLabs ให้สร้างคำพยางค์เดียวด้วยเสียง Rin soft ~40 คำ (dev 20 / held-out 20 คำคนละชุด ล็อกก่อนวิเคราะห์ ไม่กี่ร้อย credit) ฟิตค่ากลางสระจาก dev แล้วรัน held-out ครั้งเดียว (`tools/voice/eval.mjs`) ผ่าน ≥ 60% ค่อยเปิด `shapes: true` ตอนทำแพ็ก ไม่ผ่านใช้ความดังต่อ
- Dialogue manager + STT ในเครื่อง + ตัวจับเจตนา
- **จบเฟสเมื่อ:** เปิดโหมดเครื่องบินแล้วใช้งานได้ครบทั้งเช้า ประโยคไม่ซ้ำภายใน 7 วัน และปากตรงกับเสียง
