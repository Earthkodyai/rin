# 14. ความเสี่ยงหลัก

| ความเสี่ยง | โอกาส | ผลกระทบ | การรับมือ |
|---|---|---|---|
| มือถือยี่ห้อที่คุณใช้ปิดแอปจนไม่ปลุก | สูง | สูง | S1, ring log, คู่มือตามยี่ห้อ และ Diagnostics |
| WebView ลื่นไม่พอ | กลาง | กลาง | เกณฑ์ S2 → Plan B Unity (ยังติดตั้งอยู่) |
| Play ไม่อนุมัติ exact alarm หรือ full-screen | ต่ำ–กลาง | สูง | หน้าที่หลักคือการปลุกจริง และทำ declaration ให้ชัดเจน |
| เสียงไม่ถูกใจ หรือเงื่อนไขการใช้งานไม่อนุญาต | กลาง | กลาง | S4 คัดเสียงและตรวจ ToS |
| ภารกิจรูปพลาดหรือติดจากบนเตียง | สูง (S5: held-out 4/8) | กลาง | ภารกิจหลักเป็น QR, รูปเป็นทางเลือกที่ต้องผ่าน self-test, gate เปิดไฟ, ภารกิจสำรองเสมอ |
| ตรวจการกลับไปนอนผิดจนผู้ใช้หงุดหงิด | สูง | กลาง | ขั้นถามยืนยัน, เกณฑ์ที่ระมัดระวัง และปิดได้ |
| ขอบเขตบานปลาย | สูง | สูง | ยึด MVP ใน [03-mvp.md](03-mvp.md) และจดไอเดียใหม่ไว้ใน parking lot ของ STATUS.md |
| หาผู้ทดสอบ 12 คนไม่ได้ | กลาง | สูง (เฉพาะ Play) | เริ่มชวนตั้งแต่ช่วง limited distribution |
| ค่า API พุ่ง | ต่ำ (เพราะมีเพดาน) | กลาง | hard cap + kill switch |
| ไลเซนส์แอนิเมชันหรือ asset ใน repo สาธารณะ | กลาง | กลาง | ตรวจก่อน commit หรือทำเอง |
| ชื่อ "Rin" ไปชนกับ Kagamine Rin (Vocaloid) ในตลาด voice alarm | กลาง | กลาง | ตรวจเครื่องหมายการค้า และพิจารณาชื่อแอปที่ไม่ซ้ำก่อนทำ store listing |
| เวลาไม่พอหรือหมดแรง | กลาง | สูง | ทุกเฟสส่งของที่ใช้ได้จริง และ v1.0 มีคุณค่าแม้ยังไม่มี AI สด |
