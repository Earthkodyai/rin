# 7. แผนงานทีละเฟส

เวลาในแต่ละเฟสเป็นค่าประมาณแบบ "วันทำงานเต็มวัน" ใช้เพื่อวางลำดับงาน ไม่ใช่กำหนดส่ง ถ้ามีเดดไลน์บอกได้ แล้วจะตัดขอบเขตให้

**รวมโดยประมาณ:** v1.0 ≈ 37–50 วันทำงาน · v1.1 เพิ่ม 7–10 วัน · v1.2 เพิ่ม 3–5 วัน (+ รอทดสอบปิด 14 วัน)
