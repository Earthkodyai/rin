# 3. ขอบเขตเวอร์ชันแรก (MVP)

**v1.0 — ออฟไลน์ทั้งหมด ค่าใช้จ่าย $0 ไม่มีเซิร์ฟเวอร์ ไม่มีบัญชีผู้ใช้**
1. ตั้งปลุกได้หลายเวลาและหลายวัน และต้องดังแน่นอนแม้ไม่มีเน็ต หลังรีบูต หรืออยู่ในโหมด Doze
2. หน้าจอปลุกเต็มจอ: รินหายใจ กะพริบตา มองตาม ขยับปากตามเสียง และเปลี่ยนสีหน้าตามอารมณ์
3. คุยตอบด้วยเสียงภาษาอังกฤษแบบออฟไลน์: แปลงเสียงในเครื่อง → จับเจตนา (yes/no/snooze/tired/sick/…) → เลือกประโยคจากคลังเสียง
4. ภารกิจ 1–2 ด่าน ได้แก่ สแกน QR สติกเกอร์ที่แปะไกลเตียง (ภารกิจหลัก) หรือถ่ายรูปของที่สอนไว้ (ทางเลือก, ในเครื่อง), เดินให้ครบจำนวนก้าว หรือพูดประโยคภาษาอังกฤษ (ใช้เป็นภารกิจสำรอง) และมีปุ่มปิดฉุกเฉินเสมอ
5. ~~เฝ้าดูการกลับไปนอนในช่วง 10 นาทีหลังจบภารกิจ~~ ตัดตาม D18 (2026-09-30): ปลุกจบเมื่อผ่านเกม แอปไม่ตรวจและไม่ลงโทษการกลับไปนอน ([ADR 0002](../adr/0002-no-wake-up-check.md))
6. Bond level + streak + ปลดล็อกบทพิเศษประจำวัน
7. Onboarding ที่ขอสิทธิ์ตามบริบท + หน้า Diagnostics + ปุ่ม "ทดสอบปลุกใน 1 นาที"
8. ยืนยันอายุ 18+, แจ้งชัดว่ารินเป็น AI, มีขั้นตอนรับมือวิกฤต (สายด่วนสุขภาพจิต 1323)
9. แจกผ่านบัญชี limited distribution

**v1.1 — คุยสดกับ AI** (เปิดเมื่อมีงบ): backend proxy + Claude + ชุด eval + เพดานงบ
**v1.2 — Google Play**

**ยังไม่ทำในรอบนี้ (non-goals):** iOS, ตัวละครหลายตัว, บัญชีผู้ใช้หรือการซิงก์คลาวด์, ระบบชำระเงิน, โฆษณา, ไมค์ที่ฟังตลอดเวลา, การส่งรูปขึ้นคลาวด์

> การไม่มีบัญชีผู้ใช้และไม่มีเซิร์ฟเวอร์ใน v1.0 ตัดงานด้านความปลอดภัย การลบบัญชี และแบบฟอร์ม Data safety ออกไปได้มาก
