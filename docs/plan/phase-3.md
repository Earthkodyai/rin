# เฟส 3 — ภารกิจ เกม "Rin says" และ wake-up check (≈ 6–8 วัน)

> **ตาม D16 (อนุมัติ 2026-09-28 คุณเลือกตัวที่แนะนำทุกข้อ)** · ❓ = ยังไม่ได้เลือก
> อ่านประกอบเมื่อจำเป็น: [05c-missions-sensors.md](05c-missions-sensors.md) · [08-error-handling.md](08-error-handling.md) · [3.1](../spikes/3.1-walk-vs-shake.md) · [3.2](../spikes/3.2-qr.md)

## เป้าหมาย
ปิดปลุกได้เมื่อ "ตื่นจริง" และไม่กลับไปนอนต่อ โดยผู้ใช้ไม่ต้องเตรียมอะไรล่วงหน้า (ไม่ต้องพิมพ์ ไม่ต้องติด ไม่ต้อง setup)
- **ปิดปลุก:** เกม "Rin says" หรือเดิน 30 ก้าว (Rin picks หมุนรายวัน) · ฉุกเฉินกดค้าง 3 วิ (log ให้เฟส 5 หัก Bond)
- **กันกลับไปนอน:** wake-up check หลังปิดปลุก ถ้าไม่ตอบ = ดังอีกรอบพร้อมเกม
- ข้อจำกัดที่ยอมรับ (D16): ไม่มีภารกิจไหนพิสูจน์ว่าลุกจากเตียงแล้ว งานนี้ตกอยู่ที่ wake-up check + สัญญาณ bed-return

## เกม "Rin says"
- **กติกา:** รินแสดงลำดับท่า แล้วผู้ใช้แตะแผ่นตามลำดับ ผ่าน 3 รอบ ยาว 3 → 4 → 5 (≈ 60–90 วินาที) · แตะผิด = เล่นรอบเดิมใหม่ด้วยลำดับ**ใหม่**ที่ยาวเท่าเดิม (ไม่หักอะไร ท่องจำลำดับไม่ได้)
- **4 แผ่น** แต่ละแผ่นมีท่าของริน สี รูป ตำแหน่ง และเสียงโน้ตของตัวเอง (ตาบอดสีเล่นได้ ฟังอย่างเดียวก็เล่นได้) ปุ่มใหญ่ แตะอย่างเดียว ธีมมืดสำหรับห้องมืด
- **native ล้วน (กฎ ring path):** ลำดับแสดงด้วยแผ่นที่สว่างขึ้น + เสียงโน้ตใน Compose ส่วนรินใน WebView ทำท่าตามเป็นของแถม ถ้า WebView ล่ม เกมยังเล่นได้ครบ · สุ่มด้วย seed ต่อการดัง ออฟไลน์ ไม่มีเน็ต
- **เสียงปลุก:** ใช้กลไกเดิม ระหว่างที่แตะถูกเสียงเบาลง (≤ 0.15) ไม่มีความคืบหน้า 30 วิก็กลับมาดังเต็ม · ช่วงรินแสดงลำดับ เสียงปลุกหรี่ลงให้ได้ยินโน้ต
- ท่าที่ใช้: ❓ (wave, nod, clap, huff; เลือกตอน 3.3 จากการดูบนเครื่อง) จาก 9 ท่าที่มีอยู่ (2.4) เลือกท่าที่ดูต่างกันชัดในกรอบเต็มตัว
- log: `MISSION_PASSED` พร้อม `rounds`, `mistakes`, `tookMs`

## Wake-up check
- 5 นาทีหลังปิดปลุกด้วยภารกิจ ตั้ง exact alarm อีกตัว (ring path เดิม native ล้วน) รินถามเบาๆ ว่า "You're up, right?"
- ตอบ = เกมสั้น 1 รอบ ยาว 3 (≈ 10–15 วิ) ภายใน 60 วิ · ไม่ตอบ = ดังเต็มอีกรอบพร้อมเกมเต็ม + log `back_to_bed_confirmed`
- สัญญาณ bed-return (ใช้ประกอบ log และปรับระดับเสียง ไม่ใช่ตัวตัดสิน): เครื่องวางราบนิ่ง จอดับ แสงน้อย ไม่มีก้าวตั้งแต่ปิดปลุก
- ตั้งต่อปลุก: เปิดเป็นค่าเริ่มต้นในปลุกที่มีภารกิจ ปิดได้รายปลุก ปลุกที่เป็น None (งีบ/ทดสอบ) ปิด

## จบเฟสเมื่อ (14 เช้าจริง)
- ปิดปลุกด้วยเกมหรือเดินได้ภายใน 2 นาทีหลังเริ่ม ≥ 90% ของเช้า
- wake-up check ทำงานทุกเช้า (ตอบ หรือดังซ้ำตามกติกา) และรายงานจำนวนเช้าที่กลับไปนอนตามจริง
- ไม่มีกรณีหัก Bond ผิดคน (event ฉุกเฉิน/กลับไปนอนทุกรายการตรงกับที่เกิดจริง)
