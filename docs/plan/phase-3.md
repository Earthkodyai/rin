> **ตาม D17 (2026-09-28)** ซึ่งแทนส่วนเกมของ D16 และ **D18 (2026-09-30)** ที่ตัด wake-up check · ❓ = ยังไม่ได้เลือก · เหตุผลเต็ม: [ADR 0001](../adr/0001-games-replace-out-of-bed-missions.md), [ADR 0002](../adr/0002-no-wake-up-check.md)

## เป้าหมาย
ปิดปลุกได้เมื่อ "ตื่นจริง" ผ่านเกมกับริน ผู้ใช้ไม่ต้องเตรียมอะไรล่วงหน้า
- **ปิดปลุก:** 1 ใน 3 เกม (Rin picks หมุนรายวัน หรือระบุเกมต่อปลุก) · ฉุกเฉินกดค้าง 3 วิ (log ให้เฟส 5 หัก Bond)
- **หลังปิดปลุก แอปไม่ทำอะไรต่อ (D18):** ไม่มี wake-up check ไม่ดังซ้ำ ไม่เฝ้าเซนเซอร์ การตื่นต่อเป็นเรื่องของผู้ใช้ Snooze (5 นาที × 3) คือช่วงเผื่อ
- ข้อจำกัดที่ยอมรับและบอกตรงๆ: เกมพิสูจน์ว่าสมองตื่นตอนปลุกหยุด ไม่ได้พิสูจน์ว่าลุกจากเตียงหรือไม่กลับไปนอน

## กติการ่วมของทุกเกม (กฎ ring path)
- สุ่มลำดับ ตรวจคำตอบ และเล่นเสียง อยู่ใน **Kotlin** (unit test ได้ โกงผ่านหน้าเว็บไม่ได้) · รินใน WebView รับคำสั่งแล้วแสดงเท่านั้น
- ปุ่มตอบเป็น native ขนาดใหญ่ แตะอย่างเดียว ธีมมืด · **ถ้า WebView ไม่พร้อมหรือล่ม เกมเดิมเล่นต่อแบบ 2D native** ปลุกยังปิดได้เสมอ
- ออฟไลน์ทั้งหมด สุ่มด้วย seed ต่อการดัง · ผิด = เล่นใหม่ด้วยโจทย์ใหม่ ไม่มีการหักอะไรในเกม
- เสียงปลุก: กลไกเดิม ตอบถูกแล้วเสียงเบาลง (≤ 0.15) ไม่คืบหน้า 30 วิกลับดังเต็ม · ช่วงรินสาธิตหรือพูด เสียงปลุกหรี่ลงให้ได้ยิน
- log: `MISSION_PASSED` พร้อม `game`, `rounds`, `mistakes`, `timeouts`, `tookMs`

## 1) สลับแก้ว
- แก้ว 3 ใบบนโต๊ะหน้าริน บอลอยู่ใต้ 1 ใบ มือรินวางบนแก้วแล้วเลื่อนสลับ (ไม่ใช่มือจับแก้วแบบสัมผัสจริง) · ผู้ใช้แตะปุ่มแก้ว 1–3
- **ถูกติดกัน 3 ครั้ง** (เดาถูก 1/27) ผิด = นับใหม่จาก 0 พร้อมสลับชุดใหม่
- สลับ 4 → 5 → 6 ครั้งตามลำดับที่ถูกติดกัน (ผิดแล้วกลับไป 4) · สลับครั้งละ 450 ms เว้น 150 ms (dev 5/5 "fine" ไม่ต้องปรับ) · หน้าปลุกเรนเดอร์ 60 fps (หน้าหลักยังคง 30) เพราะผู้ทดสอบเห็นว่าลื่นกว่าชัดเจน และ 14T ทำได้ 58–60 fps
- มือรินดันแก้วเข้ามาตรงกลาง สลับแก้วกัน แล้วดึงกลับข้างตัวเอง (แขนสั้นข้ามกลางตัวไม่ได้ ไม่งั้นทะลุหน้าอก) · แตะแก้ว = แตะโซนของแก้วนั้น แบ่งครึ่งทางระหว่างแก้ว
- เล่นด้วยตาเท่านั้น (ข้อจำกัดด้านการเข้าถึง บันทึกไว้)

## 2) Colour pads
- ตาราง 2×2: แดง (ซ้ายบน) น้ำเงิน (ขวาบน) เหลือง (ซ้ายล่าง) เขียว (ขวาล่าง) แต่ละช่องมีโน้ตของตัวเอง (เล่นด้วยหูได้ ตาบอดสีเล่นได้)
- ตอนสาธิตเห็น**แค่มือริน**: ภาพมือเรนเดอร์จากโมเดลรินตอน build (แบบเดียวกับ stills) เลื่อนไปกดช่อง ช่องสว่างขึ้นพร้อมโน้ต · ทำใน native ทั้งหมด
- 3 รอบ ยาว 3 → 4 → 5 · **จับเวลา 3 วินาที** ก่อนแตะแรกและระหว่างแตะแต่ละครั้ง
- **ช้าเกินหรือแตะผิด:** ตัดไปหน้ารินเต็มตัวดุ (งอน + huff + ประโยคแซวเบาๆ ตาม character sheet "warm, calm, gently teasing" และ 05e) ราว 2–3 วิ แล้วเล่นรอบเดิมด้วยลำดับใหม่

## 3) พูดตามภาษาอังกฤษ
- รินพูดประโยคสั้นพร้อมซับไตเติล ผู้ใช้พูดตาม 3 ประโยค · Vosk จำกัดคำตามประโยคนั้น + คลาส unknown + เกณฑ์ความมั่นใจ (ตาม S3)
- พูดได้ 2 ครั้งต่อประโยค ไม่ผ่านแล้วเปลี่ยนเป็นแตะคำเรียงประโยค (ไม่ติดค้างเพราะสำเนียงหรือพูดงึมงำ)
- ไมค์เปิดเฉพาะช่วงฟังและมีสัญลักษณ์บอก (CLAUDE.md) · เสียงปลุกเงียบระหว่างฟัง
- ปุ่ม **"Can't talk right now"** สลับไปอีก 2 เกม · ไม่มีสิทธิ์ RECORD_AUDIO = Rin picks ไม่เลือกเกมนี้
- เสียงริน: ใช้เสียง dev ไปก่อน แทนด้วยคลังเสียง "Rin soft" ในเฟส 4 · Vosk +~50 MB (อนุมัติแล้วใน D15)
- ต้องวัดก่อนใช้จริง: อัตรารับเสียงงึมงำ/เสียงนอกประโยคผิด (ล็อกเกณฑ์ก่อนเก็บข้อมูล)

## Wake-up check — ตัดแล้ว (D18, 2026-09-30)
- เดิมจะถาม "You're up, right?" 5 นาทีหลังปิดปลุก (colour pads รอบสั้นใน 60 วิ ไม่ตอบ = ดังซ้ำ) พร้อมสัญญาณ bed-return
- ตัดเพราะ: เครื่องที่วางไว้บนเตียงตอนผู้ใช้ไปอาบน้ำ กับเครื่องข้างคนที่หลับต่อ ให้สัญญาณเหมือนกัน (ราบ นิ่ง จอดับ ไม่มีก้าว) จึงต้องดังใส่เตียงว่างหรือปล่อยคนหลับ · ปลุกส่วนใหญ่จบด้วย snooze และ snooze สั้นๆ ไม่เป็นผลเสียที่วัดได้ · เครื่องมือบังคับตัวเองที่เข้มเกินถูกเลิกใช้ · รายละเอียดและแหล่งอ้างอิงใน [ADR 0002](../adr/0002-no-wake-up-check.md)
- ถ้าผู้ทดสอบภายหลังอยากได้โหมดเข้ม ดีไซน์ 3.6 (ปุ่ม "ไปอาบน้ำ" เลื่อน check, ข้ามเมื่อเครื่องถูกพกเดิน, วัดแรงสั่นที่นอนก่อน) กลับมาเป็นตัวเลือกรายปลุกได้
