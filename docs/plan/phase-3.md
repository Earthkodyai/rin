# เฟส 3 — ภารกิจและเซนเซอร์ (≈ 6–8 วัน)

> อ่านประกอบเมื่อจำเป็น: [05c-missions-sensors.md](05c-missions-sensors.md) · [08-error-handling.md](08-error-handling.md)
- Mission framework (`start / progress / verify / fallback`), คลังภารกิจ และการสุ่มภารกิจรายวัน
- ภารกิจสแกน QR (หลัก: วัดผ่านครั้งแรก ≥ 90% และสแกนจากเตียงไม่เจอ), ภารกิจถ่ายรูปของที่สอนเอง (ทางเลือก: setup นำทางหลายมุม + สแกนเตียง + self-test ตาม [S5](../spikes/S5-mlkit.md)), ภารกิจเดิน, ภารกิจพูดประโยคภาษาอังกฤษ และปุ่มปิดฉุกเฉิน (กดค้าง 3 วินาที โดยหัก Bond)
- Bed-return detector + ขั้นตอนถามยืนยัน
- **จบเฟสเมื่อ:** ผ่านภารกิจตั้งแต่ครั้งแรก ≥ 90% ในบ้านของคุณ และตลอด 14 เช้าไม่มีกรณีหัก Bond ผิดคนเลย
- **แผนงาน (D15, 2026-09-28):** 3.1 framework + หน้าปลุกใหม่ + ภารกิจเดิน · 3.2 QR · 3.3 พูดประโยค · 3.4 bed-return + log 14 เช้า · 3.5 ถ่ายรูปของที่สอนเอง (ทางเลือก) · เสียงระหว่างภารกิจเบาลง กลับดังเมื่อไม่คืบหน้า 30 วิ · Bond ยังไม่มี: บันทึกเป็น event ให้เฟส 5
