# 5.2 Emotion engine (ระบบอารมณ์)
- **สถานะอารมณ์ (mood):** `sleepy`, `cheerful`, `proud`, `worried`, `pouty`, `sulky`, `relieved`
- **อินพุต (event):** `alarm_fired`, `user_spoke(intent)`, `snooze`, `mission_started/completed/failed`, `emergency_dismiss` (`back_to_bed_*` ตัดตาม D18) รวมถึง streak, bond และเวลาที่ใช้ตื่น
- **เอาต์พุตต่อหนึ่งจังหวะ:** `{ emotion, intensity 0–1, gesture, lineId | text }`
- **การแมปไปยัง VRM:** ใช้ preset `happy/angry/sad/relaxed/surprised` + `blink` + `lookAt` + รูปปาก `aa/ih/ou/ee/oh` ท่า "งอน" คือ `angry` ระดับเบาผสมท่ากอดอก (ตรวจ blendshape เพิ่มเติมที่ VRoid ให้มาในเฟส 2)
- **ความลื่น:** blend สีหน้าแบบ lerp 150–300 ms, crossfade แอนิเมชัน 200–400 ms, มีการหายใจ กะพริบตา และขยับตาเล็กๆ แบบสุ่มตลอดเวลา
- **แอนิเมชัน (VRMA):** idle หายใจ, หาว, บิดขี้เกียจ, โบกมือ, ปรบมือ, พยักหน้า, ส่ายหน้า, กอดอกงอน, ดีใจ
- **Lip sync:** คลิปในคลังมี timeline รูปปาก (viseme) ที่คำนวณไว้ตอน build ปากจึงตรงเสียงแม้ออฟไลน์ ถ้าไม่มี timeline ให้ใช้ความดังของเสียง (RMS) ขับรูปปาก `aa` แทน
- **งบประสิทธิภาพ:** เป้า 60 fps บนมือถือระดับกลาง ต่ำสุด 30 fps · โมเดล ≤ 10–15 MB (texture 1024–2048) · ใช้ `VRMUtils` รวม morph · ไม่มีเงาหรือ post-processing · จำกัด pixel ratio · หยุด render เมื่อไม่ได้แสดงผล
- **ภาพสำรอง:** เรนเดอร์ PNG 6–8 สีหน้าจากโมเดลเก็บไว้ ใช้เมื่อ WebView ล้มหรือโหลดช้า
- **ชั้นตัวละคร (2.1):** `web/character/` (Vite 8 + TS + three 0.186.1 + three-vrm 3.5.5) ถูก Gradle task `buildCharacterWeb` build ลง generated assets `character/` ทุกครั้ง (ต้องมี Node/npm; CI ใช้ setup-node) · `character/CharacterView.kt` โหลดผ่าน `WebViewAssetLoader` (ออฟไลน์ล้วน: นอก assets ตอบ 404, ห้าม navigate, ไม่มี file/content access) · bridge `RinBridge` = `addWebMessageListener` จำกัด origin, protocol v1 JSON (`ready`/`error` → แอป, `pause`/`resume` → หน้าเว็บ) ฝั่งละตัว `bridge.ts` / `CharacterMessage.kt` ไม่รู้จัก type ไหนก็ข้าม · จำกัด 30 fps และ pixel ratio 2 (S2) · canvas โปร่งใส ภาพนิ่งอยู่ด้านบนแล้ว fade ออกเมื่อเฟรมแรกของรินมา · ภาพนิ่งแทนเมื่อ: ไม่มีโมเดล, WebView ไม่รองรับ bridge, หน้าเว็บ error, ไม่มีเฟรมแรกใน 10 วิ, หรือ renderer ล้ม (`onRenderProcessGone` คืน true) · โมเดล: `rin.vrm` ก่อน แล้ว `dev.vrm` (ตัวอย่าง VRoid ใน `app/src/debug/assets`, git-ignore) · กล้องจับที่ bone หัวของโมเดล
- **พบใน 2.1:** WebView ที่วางตรงใน Compose `AndroidView` หยุด invalidate หลังโหลดเมื่อหน้าเว็บใช้ WebGL (HTML ธรรมดาไม่เป็น) รินจึงไม่ขึ้นจอบน 14T (WebView 153, HyperOS 2) แก้ด้วย FrameLayout ครอบ WebView (bisect: invalidate 6 → 140 ใน 8 วิ) · ทดสอบ renderer ล้ม: `am broadcast -n <pkg>/.debug.DebugCharacterReceiver --es cmd crash` → ภาพนิ่งขึ้น แอปไม่ล้ม (pid เดิม)
- **พฤติกรรม (2.2, 2026-09-28):** `web/character/src/` = `emotion.ts` (ล้วนตัวเลข มี vitest 11 ข้อ รันทุกครั้งใน `npm run build`) + `behaviour.ts` (กระดูก/สีหน้า) + `vroid.ts` · ตารางอารมณ์อยู่ที่ `moods.json` ไฟล์เดียว (น้ำหนัก expression + `lid` + ท่าหัว pitch/yaw/roll + `gaze`) และ `MoodContractTest` ฝั่ง Kotlin อ่านไฟล์นี้ enum `Mood` จึงไม่หลุดจากหน้าเว็บ · blend แบบเวลาคงที่ 200 ms (smoothstep ไม่ใช่ไล่แบบ exponential จึงวัดจุดจบได้) เปลี่ยนกลางทางเริ่มจากค่าปัจจุบัน · **พบ:** preset `happy`/`relaxed` ของ VRoid หลับตา (`Fcl_ALL_Joy/Fun`) รินที่ร่าเริงทั้งวันจะไม่เคยมองผู้ใช้ จึงสร้าง expression `smile` จาก `Fcl_MTH_Fun` + `Fcl_BRW_Fun` (ตาเปิด) ก่อน `combineMorphs` โมเดลที่ไม่ใช่ VRoid ใช้ `happy` เบาๆ แทน · `happy` เต็มที่เก็บไว้ให้ท่าแตะหัว
- **มองตาม/แตะหัว (ตัวเลือกของคุณ 2026-09-28 ทุกข้อเป็นตัวที่แนะนำ):** มองกล้อง + ขยับตาเล็กๆ ทุก 0.8–2.5 วิ + เหลือบออกทุก 6–12 วิ, นิ้วแตะแถบค้างไว้ = ตาและหัวมองตามนิ้ว (หัวตาม ~35% ช้ากว่าตา) ไม่ใช้ sensor · แตะ **หัวเท่านั้น** (ทรงกลมจากกระดูกหัวถึงยอดผม) = ดีใจ 1.5 วิ + พยักหน้า + haptic `CLOCK_TICK` (ไม่ต้องขอสิทธิ์), cooldown 1 วิ, แตะส่วนอื่นไม่มีผล (SFW), **ไม่เพิ่ม Bond** (กันปั๊มคะแนน), หน้าเว็บส่ง `tap` ให้แอปเผื่อเฟส 3 · อารมณ์บนหน้าหลักจนกว่าเฟส 3 จะมี: `DefaultMood` 22:00–05:59 sleepy นอกนั้น cheerful
- **protocol v1 เพิ่ม (ยังเป็น v1 เพราะข้ามได้):** แอป → หน้า `{"type":"emotion","mood","intensity","at"}` · หน้า → แอป `emotion {mood, ms:{toPage,total}}` และ `tap {part:"head"}` · อารมณ์เริ่มต้นส่งทาง query `mood=`/`intensity=` เฟรมแรกจึงถูกอารมณ์ ไม่มี blend · แอปส่งอารมณ์เฉพาะตอนหน้าพร้อมและอยู่บนจอ (เปลี่ยนตอน pause รอ resume) เวลาที่วัดจึงไม่รวมช่วงปิดจอ · debug: `am broadcast -n <pkg>/.debug.DebugCharacterReceiver --es cmd mood --es mood pouty [--ef intensity 0.5]` แล้วดู logcat `RinChar` · `npm run dev` โหลดโมเดลตัวอย่างได้ที่ `?model=/@fs/<repo>/app/src/debug/assets/character/model/dev.vrm&mood=cheerful`
- **ผลบน 14T (2.2):** เปลี่ยนอารมณ์ 20/20 ครั้ง ≤ 300 ms (ต่ำสุด 183, มัธยฐาน 217, สูงสุด 241 ms จากแอปส่งถึงเฟรมสุดท้ายของ blend; ผ่าน bridge ≤ 4 ms) · เฟรมแรก warm 1.45–1.59 วิ (เท่า 2.1) · กรอบภาพแขวนจากยอดโมเดล (Box3 ของ skinned mesh) ผมไม่โดนตัดแล้ว · คุณทดสอบด้วยมือ: ผมพอดี, แตะหัวได้ ^^ + พยักหน้า + สั่น, แตะอกไม่มีผล, ตามนิ้วได้
