# 2. ตลาดและสิ่งที่เรียนรู้จากคู่แข่ง

| แอป/เว็บ | ทำอะไร | สิ่งที่เราเอามาใช้ | สิ่งที่เราทำต่าง |
|---|---|---|---|
| **Alarmy** | ภารกิจถ่ายรูป: AI สุ่มสิ่งของในบ้าน ต้องถ่ายให้ตรงจึงปิดเสียงได้ มีแพ็กเกจสมาชิกรายเดือน | ยืนยันว่า photo mission ได้ผลจริงในตลาด | ประมวลผลในเครื่อง (ฟรีและเป็นส่วนตัว) และมีตัวละครที่ตอบสนองทางอารมณ์ |
| **Anime Alarm** (ตัวละคร Kanon) | ปลุกด้วยบทพูด 500+ แบบ แตะหัวตัวละครได้ | ตั้งเป้าคลังเสียงหลายร้อยประโยค และใช้การสัมผัสตัวละครเป็นลูกเล่นเล็กๆ | ตัวละคร 3D ที่ขยับตามอารมณ์ และมีภารกิจยืนยัน |
| **Hatsune Miku – Voice Alarm**, **Situation Boyfriend Alarm** | ใช้เสียงตัวละครดังหรือนักพากย์ | ตลาดแฟนคลับของ voice alarm มีอยู่จริง | ใช้ตัวละคร original ทั้งหมด จึงไม่มีปัญหาลิขสิทธิ์ |
| **EmoAlarm**, **Character Voice Alarm** | เสียง AI หลายสไตล์ + วอลเปเปอร์ | ความหลากหลายของเสียงดึงดูดผู้ใช้ | เน้นตัวละครเดียวที่ลึก (ตามข้อ 4.3 ในการบ้าน) |
| **Wakeup Buddy** (Android), **ClockClanker**, **Wake AI**, **Avo**, **Character Alarm**, **Snoozd** | นาฬิกาปลุกที่คุยกับ AI (เกิดขึ้นช่วงปี 2025–26) | ยืนยันว่ามีความต้องการในตลาด | ส่วนใหญ่มีแค่เสียง ไม่มีอวตารที่ขยับได้ ไม่มีภารกิจ และไม่มีระบบอารมณ์ต่อเนื่อง |
| **Grok "Ani"** (xAI) | อวตาร 3D อนิเมะ มีค่าความชอบ −10 ถึง +15 แบ่ง 5 ระดับ ใช้แอนิเมชันที่ทำไว้ล่วงหน้า โดย AI เลือกว่าจะเล่นท่าไหน | **ใช้สถาปัตยกรรมแบบเดียวกัน:** LLM ส่งแท็กอารมณ์และท่าทาง แล้ว state machine เล่นคลิปที่ทำไว้ | บทเรียนเชิงลบ: Ani ผูกค่าความชอบเข้ากับเนื้อหาทางเพศจนโดนวิจารณ์หนัก เราไม่ทำแบบนั้นเด็ดขาด |

**โค้ดโอเพนซอร์สที่ศึกษาได้**
- `anjaydo/vroid-ai-companion` — Next.js + three.js แสดงอวตาร VRM มี lip sync จากเสียง และใช้แอนิเมชัน Mixamo (ใกล้เคียงเลเยอร์ตัวละครของเรามาก)
- `tk256ailab/vrm-viewer` — ตัวอย่างการเล่นไฟล์ VRMA (VRM Animation)
- เอกสาร three-vrm: `VRMUtils` มีฟังก์ชันรวม morph target เพื่อกันแครชบนมือถือ
- dontkillmyapp.com — คู่มือแยกตามยี่ห้อมือถือ สำหรับตั้งค่าไม่ให้ระบบปิดแอปเบื้องหลัง

**จุดยืนของเรา (positioning):** ตัวละครเดียวที่รู้จักคุณ + ยืนยันว่าลุกจริง + ตอบสนองทางอารมณ์ + ออกแบบให้ใช้หน้าจอน้อยที่สุด (ปลุกเสร็จแล้วปล่อยคุณไปใช้ชีวิต)
