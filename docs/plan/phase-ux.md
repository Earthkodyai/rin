# เฟส UI/UX (ก่อน limited distribution ตาม D28)

> เริ่ม 2026-10-01 หลังโมเดลรินของคุณเข้าแอป · ขั้นตอน: ความต้องการ → mockup ให้เลือก → ทำใน Compose → ลองบนเครื่อง (คุณตัดสินด้วยตา) · อ่านประกอบ: [phase-3.md](phase-3.md) (เกม), [05a-emotion-engine.md](05a-emotion-engine.md) (มุมกล้องของริน)

## สภาพปัจจุบัน
- ธีมเป็นค่าตั้งต้นของเทมเพลต Android (ม่วง) + dynamic color (สีตามวอลเปเปอร์ แต่ละเครื่องไม่เหมือนกัน) + ฟอนต์ค่าตั้งต้น
- ตั้งเวลาด้วยแป้นนาฬิกาของ Material

## ความต้องการ (คุณ, 2026-10-01)
1. **ความรู้สึก:** UI แบบเกม/อนิเมะที่สนุก (playful) ผสมกับทิศทางอื่นที่คุณชอบ: เลือกจาก mockup 2–3 แบบ
2. **สี:** ชุดสีแบรนด์คงที่ (ปิด dynamic color) ให้เข้ากับริน (ผมชมพู ตาเขียว) และภาพหน้าร้านเหมือนกันทุกเครื่อง
3. **รินครึ่งตัว:** จุดที่ UI รกหรือมีของเยอะ ให้เห็นรินแค่ครึ่งตัว (ทุกจุดในแอป)
4. **ตั้งเวลาแบบเลื่อน** แทนแป้นนาฬิกา: mockup ทั้งแบบวงล้อเลื่อน (ชั่วโมง/นาที) และแบบแถบเลื่อนแนวนอน ให้คุณเลือก
5. **เกมสลับแก้ว:** ขยายทั้งฉาก (ริน โต๊ะ แก้ว) ให้เต็มจอมากกว่านี้
6. **หน้าที่สำคัญก่อน:** หน้าหลัก (รินกับรายการปลุก), หน้าปลุก + เกม, ตัวตั้งปลุก

## สิ่งที่คุณเลือก (2026-10-01, จาก mockup บน canvas "RinAlarm UI directions")
- ทิศทาง **Day/night**: กลางวัน = "Candy morning" (ครีม ชมพู มิ้นต์), กลางคืน = กรมท่ามีดาว (mockup C) รูปทรงเดียวกัน
- สลับตาม **เวลา (กลางคืน 19:00–05:59) + การตั้งค่าของแอปเอง** (Auto / Day / Night ในหน้าตั้งค่า) ไม่ใช่ dark mode ของเครื่อง
- ตั้งเวลาแบบ **วงล้อเลื่อน**
- เกมถ้วย **3D เหมือนเดิม แค่ขยาย scale** (ริน โต๊ะ ถ้วย) · ธีมเดียวกันทั้งแอป
- ฟอนต์ **M PLUS Rounded 1c** (OFL) ตัดเหลืออักษรละตินและเครื่องหมาย ~47 KB ต่อน้ำหนัก ใบอนุญาตใน assets/licenses

## งาน
- **UX.1 ✅ ธีม:** ชุดสีกลางวัน/กลางคืน (ตัวอักษรบนปุ่มผ่าน contrast: ชมพูปุ่ม #CF346D ≈4.9:1 → #CC3169 ใน UX.2 ≈5:1 และเป็นตัวอักษรบนพื้นครีมได้ 4.6:1, ชมพูอ่อน #FF6F9C ใช้ตกแต่งเท่านั้น), ปิด dynamic color, ฟอนต์, ThemeClock (ตั้งค่า + เวลา เช็กทุกนาที), แถบสถานะตามธีมแอป, ปุ่ม Look ในตั้งค่า · 345 เทสต์
- **UX.2 ✅ หน้าหลัก:** รินครึ่งตัว (มุมกล้อง waist ใหม่ 0.72 ม. + ภาพนิ่งชุด waist) บนแผงสูง 216 dp (คุณขอพื้นที่ให้รายการปลุกมากขึ้น) มีพระอาทิตย์/พระจันทร์ บทพูดอยู่ในกรอบคำพูดข้างเธอ, ปุ่มพักวัน/ป่วยแบบเม็ดยา, หัวรายการ "Next: today/tomorrow", การ์ดสติกเกอร์ (จุดวัน, ป้ายเกม), ปุ่ม Add alarm สีชมพู, เวลาบนการ์ดเป็น HH:mm อย่างเดียว, แถบเตือน setup สีแดงเข้ม · `Modifier.sticker` ใช้ต่อใน UX.3–5 · เทสต์ contrast ของทุกคู่สีตัวอักษร · ลองบนเครื่องแล้ว (กลางวัน)
- **UX.3 ✅ ตัวตั้งปลุก:** วงล้อเลื่อน (วนได้, AM/PM ถ้าเครื่องเป็น 12 ชม.), ปุ่มวันกลม, ไทล์เกม, การ์ดเสียงปลุก, ปุ่ม Save alarm · ข้อความภาษาอังกฤษทั้งแอป · ไม่มีการสั่นใน UI · กรอบคำพูดรินมีจุดสองจุด · เอาป้าย AI ออก (D29)
- **UX.4 ✅ หน้าปลุก + เกม:** รินครึ่งตัวในวิวเต็มจอที่ไม่เปลี่ยนขนาด (แถบเวลาและแผ่นด้านล่างวางทับ หน้าเว็บจัดกล้องให้พอดีช่องที่เหลือ), ฉากถ้วยใหญ่ขึ้น (ถ้วยกว้าง ~3/4 จอ), แผ่นด้านล่างมีลายพื้นหลังเลื่อนช้าๆ (ลายของเราเองตามภาพอ้างอิงของคุณ), เกมกดตามสีพื้นเชื่อมกับแผ่นด้านล่าง, เกมพูดตามรินมีกล่องประโยคลอยกลางอก · ลองครบสามเกมบนเครื่องแล้ว · คางแหลมแก้ในแอปไม่ได้ (ต้องแก้ทรงหน้าใน VRoid)
- **UX.5 ✅ หน้าอื่น:** ตั้งค่า, privacy, diagnostics, QR setup เป็นการ์ดแบบหน้าตั้งปลุก (ชิ้นส่วนกลางใน ui/common/RinPage.kt) · onboarding มีจุดบอกขั้น และรินยิ้มบนแผงต้อนรับ (ภาพนิ่ง) · ลองบนเครื่องแล้ว 3 หน้า (กลางคืน)
- UX.6 ภาพนิ่ง ✅ (ตรงกับรินตัวจริงทั้งหน้า home และหน้าปลุก) + คุณดูทุกหน้าด้วยตาทั้งกลางวัน/กลางคืน
- UX.7 เสียง (D30): เพลงธีมปลุก (เสียงบี๊บเดิมเป็นตัวสำรอง) + เพลงแอปทุกหน้า ปิดได้ในตั้งค่า · เพลงจาก ElevenLabs Music ก่อน 2026-10-30
- UX.8 tutorial (D30): ต่อจาก onboarding, รินพูดในกรอบคำพูดด้วยคลิปเดิม, รอบลองเล่นแต่ละเกม

## ข้อจำกัดที่ต้องรักษา
- ปุ่มแตะอย่างเดียว ไม่มีช่องพิมพ์ ปุ่มอันตรายต้องกันกดพลาด (คุณกดพลาดบ่อย, เฟส 2)
- เกมคงจังหวะที่ล็อกไว้ตอน held-out (3.3/3.4/3.5) โซนแตะของถ้วยต้องตามขนาดใหม่
- ปลุกต้องดังได้แม้หน้าเว็บของรินพัง (ภาพนิ่งแทน)
- ภาพนิ่งของรินต้องตรงกับมุมกล้องใหม่ (render-stills)
