# 5.6 ความปลอดภัยของตัวละคร (companion safety)
- แจ้งว่ารินเป็น AI ตั้งแต่ onboarding และมีป้าย "AI" เล็กๆ บนหน้าตัวละครตลอดเวลา
- **Crisis protocol:** ถ้าผู้ใช้พูดถึงการทำร้ายตัวเอง (โหมดออฟไลน์ตรวจด้วยคำสำคัญ โหมดสดให้โมเดลช่วยตรวจ) รินจะหยุดกดดันทุกอย่าง ตอบอย่างใส่ใจ แสดงสายด่วนสุขภาพจิต 1323 และไม่หัก Bond
- ขอบเขตเนื้อหา: ไม่มีเนื้อหาทางเพศ ไม่พาความสัมพันธ์ไปทางชู้สาว และไม่ให้คำแนะนำทางการแพทย์ (ถ้าผู้ใช้บอก "I'm sick" ให้พักได้โดยไม่ถูกหัก Bond)
- **จริยธรรมของ Bond:** มีค่าต่ำสุด ลดทีละน้อยและกู้คืนได้ มีโหมด "วันพัก/วันป่วย" ปิดโหมดงอนได้ ไม่ส่ง notification ทวงถามนอกช่วงเช้า และไม่ประจานเมื่อ streak ขาด
