# 5.6 ความปลอดภัยของตัวละคร (companion safety)
- แจ้งว่ารินเป็น AI ตั้งแต่ onboarding และมีป้าย "AI" เล็กๆ บนหน้าตัวละครตลอดเวลา
- **Crisis protocol:** ตั้งแต่ D21 ผู้ใช้ไม่ได้พิมพ์หรือพูดอิสระ แอปจึงตรวจไม่ได้ สายด่วนสุขภาพจิต 1323 เป็นข้อความคงที่ในแอป (ที่วางตัดสินในเฟส 5/6)
- ขอบเขตเนื้อหา: ไม่มีเนื้อหาทางเพศ ไม่พาความสัมพันธ์ไปทางชู้สาว และไม่ให้คำแนะนำทางการแพทย์ (วันป่วยตั้งในหน้าตั้งค่า ไม่มีเกม ไม่งอน)
- **ไม่กดดันข้ามวัน (D22):** ไม่มี Bond หรือ streak จึงไม่มีอะไรให้เสียหรือประจาน · มีโหมด "วันพัก/วันป่วย" ปิดโหมดงอนได้ และไม่ส่ง notification ทวงถามนอกช่วงเช้า
