**ประมาณการค่า LLM ต่อการปลุก 1 ครั้ง (คุย 4 จังหวะ)**
สมมติฐาน: system prompt ~2,500 โทเคน, อินพุตใหม่ ~700 โทเคนต่อจังหวะ, เอาต์พุต ~150 โทเคนต่อจังหวะ (รวม thinking เล็กน้อย), cache read ≈ 0.1× ราคาอินพุต และ cache write = 1.25×

| รุ่น | ราคาต่อ 1M โทเคน (อินพุต/เอาต์พุต) | ≈ ต่อการปลุก | ≈ ต่อผู้ใช้ต่อเดือน (ปลุกทุกวัน) |
|---|---|---|---|
| Claude Opus 5 | $5 / $25 | $0.04–0.06 | $1.2–1.8 |
| Claude Sonnet 5 | $2 / $10 | ~$0.02 | ~$0.6 |
| Claude Haiku 4.5 | $1 / $5 | ~$0.015 (system prompt สั้นกว่า 4,096 โทเคนจึงไม่ถูก cache) | ~$0.5 |
