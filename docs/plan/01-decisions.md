**สิ่งที่เปลี่ยนจากการบ้านเดิม**
- "ค่าความสัมพันธ์" เปลี่ยนเป็น **Bond level** และบทพูดไม่เชิงชู้สาว
- ภารกิจ "ถ่ายรูปอ่างล้างหน้า" เปลี่ยนเป็น **เป้าหมายที่ไม่มีกระจก** (แก้วน้ำ ก๊อกน้ำในครัว หน้าต่าง รองเท้า) เพราะกระจกอาจถ่ายติดตัวผู้ใช้ และหลัง S5 ภารกิจหลักเปลี่ยนเป็น **สแกน QR สติกเกอร์ที่แปะไว้ไกลเตียง** ส่วนถ่ายรูปเป็นของที่ผู้ใช้สอนเองและผ่าน self-test
- "ห้ามกลับไปนอน" เปลี่ยนเป็นการตรวจจับที่ต้องถามยืนยันก่อนลงโทษ เพื่อลดการลงโทษผิดคน (สอดคล้องกับข้อ 4.2 REJECT ในการบ้าน)

**ทางเลือกที่พิจารณาแล้วไม่เลือก** (ใช้เขียน ADR และเล่าตอนสัมภาษณ์)
- Unity as a Library: แอนิเมชันสวยที่สุด แต่แอปใหญ่ขึ้นหลายสิบ MB เปิดช้าตอนปลุก และผูกเข้ากับแอป Kotlin ได้ยาก → เก็บไว้เป็น Plan B
- Live2D: ลุค 2D สวยที่สุด แต่ต้องมีภาพวาดแยกเลเยอร์และการ rig (SDK ฟรีถ้ารายได้ต่ำกว่า 10 ล้านเยนต่อปี)
- Rive: เบาที่สุดและมี state machine ในตัว แต่ต้องวาดตัวละครใน Rive เอง และต้องจ่ายค่า plan เพื่อ export
- คุยสดเต็มรูปแบบ: มีชีวิตที่สุด แต่แพง หน่วง และพังง่ายในช่วงที่ห้ามพังที่สุด (ตอนปลุก)
- Flutter / React Native: ทำได้ แต่งานปลุกต้องเขียนโค้ด native อยู่ดี Kotlin จึงตรงกว่าทั้งด้านความน่าเชื่อถือของการปลุกและด้านสัญญาณที่ส่งถึงผู้คัดเลือกฝึกงาน
