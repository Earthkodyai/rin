# 5.5 เสียงและบทสนทนา
- **คลังเสียงออฟไลน์:** 300–500 ประโยค จัดกลุ่มตาม (สถานการณ์ × อารมณ์ × ระดับ Bond) ทุกประโยคมี `id, text, emotion, gesture, duration, visemes`
  - Claude Code ร่างบท (ใช้แค่โทเคนของ Claude Code ไม่มีค่า API) แล้วคุณตรวจ
  - สังเคราะห์เสียงตอน build (ตัวเลือกหลักคือ Azure AI Speech ซึ่งมี free tier ประมาณ 0.5 ล้านตัวอักษรต่อเดือนและให้ viseme สำหรับเสียง en-US ตัวเลือกรองคือ ElevenLabs) → ตัดช่วงเงียบ → ปรับความดังให้เท่ากัน (≈ −16 LUFS) → เข้ารหัส Opus mono ~24–32 kbps (500 ประโยครวมราว 6 MB)
  - เสียงต้องเป็นเสียงสังเคราะห์ที่ออกแบบขึ้นใหม่และฟังเป็นผู้ใหญ่ ห้ามโคลนเสียงคนจริงหรือนักพากย์
- **คุยแบบออฟไลน์ (ไม่ใช้ LLM):** STT ในเครื่อง → ตัวจับเจตนาแบบคำสำคัญและ fuzzy match (`affirm, deny, snooze, tired, sick, greet, thanks, unknown`) → เลือกประโยค (ไม่ซ้ำภายใน 7 วัน และถ่วงน้ำหนักตามอารมณ์กับ Bond) ถ้าจับเจตนาไม่ได้ (`unknown`) ต้องมีบทรับมุกน่ารักๆ ไว้เสมอ
- **คุยสด (v1.1):** แอปส่ง *ข้อความ* ไป backend → Claude ตอบเป็น JSON ตาม schema `{say ≤ 220 ตัวอักษร, emotion, intensity, gesture, end}` → TTS → แอปเล่นเสียงพร้อม viseme ถ้าเกิน 4 วินาทีหรือผิดพลาดใดๆ ให้ใช้ประโยคออฟไลน์ทันที ระหว่างรอให้เล่นท่า "คิด" และเสียง "Hmm~" ที่อัดไว้
  - เป้า latency ต่อหนึ่งจังหวะ: p95 ≤ 3 วินาที
