# 8. การรับมือข้อผิดพลาด

| สถานการณ์ | ตรวจจับอย่างไร | ระบบทำอะไรแทน | ผู้ใช้เห็นอะไร |
|---|---|---|---|
| สิทธิ์ exact alarm ถูกถอน | `canScheduleExactAlarms()` + broadcast ที่แจ้งว่าสถานะสิทธิ์เปลี่ยน | ตั้งปลุกแบบ inexact สำรอง + แจ้งเตือนค้างไว้ | แบนเนอร์ "รินอาจปลุกไม่ตรงเวลา — แก้ไข" |
| ผู้ใช้ไม่ให้สิทธิ์แจ้งเตือน | ตรวจตอน onboarding และทุกครั้งที่เปิดแอป | หน้าจอเต็มจะไม่ขึ้น (เสียงยังดัง) เปิดแอปจาก launcher ระหว่างดังจะเด้งหน้าปลุกให้หยุดได้ และเตือนแรงๆ ใน Diagnostics | คำอธิบายสั้นๆ พร้อมปุ่มไปหน้าตั้งค่า |
| สิทธิ์ full-screen ถูกถอน | `canUseFullScreenIntent()` | ใช้ heads-up notification โดยเสียงยังดังผ่าน service | คำเตือน |
| มือถือปิดแอปจนปลุกไม่ดัง (OEM) | ring log พบว่าพลาดหรือดังช้า | ครั้งถัดไปที่เปิดแอป แสดงคู่มือตามยี่ห้อ | รินพูดเองว่า "Your phone put me to sleep yesterday…" |
| รีบูต เปลี่ยนเวลา หรืออัปเดตแอป | receivers | ตั้งปลุกใหม่ | ไม่เห็นอะไร |
| WebView ไม่มี เก่าเกินไป หรือล้ม | `onRenderProcessGone`, timeout | แสดงภาพนิ่งตามสีหน้า โดยเสียงยังเดินต่อ | ต่อเนื่อง ไม่สะดุด |
| โมเดลโหลดนานเกิน 2.5 วินาที | timer | แสดงภาพนิ่งก่อน แล้วสลับเป็น 3D เมื่อพร้อม | ต่อเนื่อง |
| มีสายเรียกเข้าระหว่างปลุก | audio focus + สถานะการโทร | พักเสียงแล้วกลับมาดังต่อ โดยยังสั่นอยู่ | — |
| กล้องถูกปฏิเสธสิทธิ์หรือไม่ว่าง | exception | เปลี่ยนเป็นภารกิจเดินหรือภารกิจพูด | รินเปลี่ยนภารกิจให้ |
| ML Kit จำไม่ได้ซ้ำหลายครั้ง | ตัวนับจำนวนครั้ง | ผ่อนเกณฑ์ลงเล็กน้อย แล้วเปลี่ยนเป้าหมาย | รินช่วยแนะ ("closer! more light!") |
| STT แบบออฟไลน์ใช้ไม่ได้ | `isOnDeviceRecognitionAvailable` | แสดงปุ่มคำตอบด่วน | ปุ่มแทนไมค์ |
| ไม่มีเซนเซอร์นับก้าว | SensorManager | ใช้ภารกิจอื่น | — |
| ตรวจการกลับไปนอนผิด | ขั้นถามยืนยัน | ถ้าตอบภายใน 60 วินาทีจะไม่ถูกหัก Bond | คำถามน่ารักๆ |
| ฐานข้อมูลเสียหรือ migration พลาด | exception + migration tests | ใช้ค่าเริ่มต้นที่ปลอดภัย และเก็บตารางปลุกซ้ำไว้ใน DataStore | — |
| AI: timeout, 429, 5xx, refusal หรือ JSON ผิด | ประเภท error ของ SDK, `stop_reason`, ตรวจ schema | ใช้ประโยคออฟไลน์ทันที ไม่ให้เช้าสะดุด | ไม่เห็นอะไร |
| งบ AI หมด | backend ตอบ `budget_exhausted` | ปิดการคุยสดจนถึงเดือนถัดไป | ไอคอนเล็กๆ บอกว่าอยู่ในโหมดออฟไลน์ |
| API key รั่ว | alert เมื่อค่าใช้จ่ายหรือปริมาณผิดปกติ | rotate key + เปิด kill switch | — |
| ต้องปิดปลุกด่วน | — | ปุ่มปิดฉุกเฉินใช้ได้เสมอ | ไม่ติดค้างอยู่ที่หน้าจอปลุก |
