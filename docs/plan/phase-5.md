# เฟส 5 — อารมณ์ในเช้าเดียว + ตั้งค่า (≈ 2–3 วัน)

> **ตาม D22 (2026-09-30, [ADR 0004](../adr/0004-no-cross-day-state.md)):** ทุกเช้าเริ่มใหม่ ไม่มี Bond ไม่มี streak ไม่มีบทปลดล็อก ไม่มีอะไรข้ามวัน · อ่านประกอบเมื่อจำเป็น: [05a-emotion-engine.md](05a-emotion-engine.md) · [05e-companion-safety.md](05e-companion-safety.md)
> **ย่อตาม D25:** 5.1 (คืนนี้) = ปุ่มวันพัก/วันป่วย + หน้าตั้งค่า (ปิดงอน, สายด่วน 1323) + unit test · ใช้ `RingMoods` ที่มีอยู่เป็น state machine ไม่รื้อใหม่ · 5.2 (พรุ่งนี้เช้า) = ลองบนเครื่องวันพัก 1 รอบ วันป่วย 1 รอบ + checklist 05e · ไม่ทำ 7 เช้า (เลื่อนเป็นงานหลังส่ง)

- **5.2 ✅ 2026-10-01 → เฟส 5 จบ (ย่อตาม D25):** คุณลองปลุกวันป่วยบน 14T เอง: `RING_START … dayMode=sick` → Dismiss หน้าจอ ไม่มีเกม คุณบอก "ทุกอย่างโอเค" (วันพักใช้โค้ดเดียวกันต่างแค่ pool และเสียง ครอบคลุมใน unit test) · คุณตัดสายด่วน 1323 ออก (ไม่มีแชต จึงไม่มีอะไรให้ตรวจ, D21) · checklist 05e: ป้าย AI บนหน้าริน ✅, ขอบเขตเนื้อหา ✅ (บทผ่านการตรวจใน 4.1), ไม่กดดันข้ามวัน ✅ (notification มีแค่ตอนดังและปลุกที่พลาด) · **ค้างไป 6.2:** แจ้งว่าเป็น AI ในหน้า onboarding (ตอนนี้ยังไม่มี) · 7 เช้าจริงเลื่อนเป็นงานหลังส่ง
- **5.1 ✅ เขียนเสร็จ 2026-09-30:** คุณเลือกตามที่แนะนำทุกข้อ · **วันพัก/วันป่วย** = ชิปสองอันใต้แถบรินบนหน้าหลัก ครอบคลุม "ปลุกครั้งถัดไป" ไม่ว่าเมื่อไร (กดคืนนี้ได้ผลกับเช้าพรุ่งนี้) รวม snooze ของปลุกนั้น Dismiss/หยุดเองแล้วหมด หรือหมดอายุใน 24 ชม. (`DayMode`, ธงครั้งเดียว ไม่ใช่ประวัติข้ามวัน D22) · ปลุกยังดังแต่ไม่มีเกม (Dismiss ธรรมดา) รินพูด `p5.rest`/`p5.sick` ไม่งอน · วันป่วยเสียงปลุกสูงสุด `SICK_GAIN` 0.5 (~−6 dB) · **ปิดงอน** = หน้าไม่งอน ไม่มีท่า pout/huff และ pool ที่งอนล้วน (snooze.again/last, back.again/last, pads.slow/wrong, cups.wrong) เงียบ เกมเดินต่อทันที · head tap ข้ามประโยคงอน 1 ใน 5 (`PoutFilter`) · **ตั้งค่า** = ไอคอนเฟืองบนหน้าหลัก: สวิตช์ No pouting (สายด่วน 1323 ที่ทำไว้ถูกตัดออก 2026-10-01 ตามที่คุณสั่ง) · unit test 333 ผ่าน (+19)

- State machine ของอารมณ์ภายในเช้าเดียว: sleepy/cheerful ตามเวลา → pouty/sulky ตาม snooze → proud/relieved เมื่อชนะ · รีเซ็ตทุกครั้งที่ปลุก · กดค้างปิดฉุกเฉินไม่มีบทลงโทษ
- **วันพัก / วันป่วย อยู่บนหน้าหลัก กดครั้งเดียว** (คุณสั่ง 2026-09-30): ปุ่มสองปุ่มใต้รายการปลุก ไม่ต้องเข้าตั้งค่า · ร่างความหมาย (ยืนยันตอนเริ่มเฟส 5): มีผลกับปลุกที่ดังครั้งถัดไปของวันนั้น ปลุกยังดังแต่ไม่มีเกม (ปุ่ม Dismiss ธรรมดา) รินพูด `p5.rest` / `p5.sick` ไม่งอน วันป่วยเสียงเบาลง · หมดอายุเองหลังจบวันนั้น (ไม่มีอะไรข้ามวัน ตาม D22) · กดซ้ำเพื่อยกเลิก ปุ่มต้องแตะอย่างเดียว ไม่มีช่องพิมพ์ (ผู้ใช้กดพลาดบ่อย ตามที่เจอในเฟส 2)
- หน้าตั้งค่า: ปิดโหมดงอน · ~~ที่วางข้อความสายด่วน 1323 (D21)~~ ตัด (คุณ, 2026-10-01)
- เทสต์: ทุกเส้นทางของ state machine และตั้งค่าแต่ละแบบ
