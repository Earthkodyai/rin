## คู่มือผู้ทดสอบ (ส่งหลังเข้ากลุ่ม)

```
ขอบคุณที่มาช่วยทดสอบนะครับ 💗

ติดตั้ง
1. เปิดลิงก์นี้ด้วยบัญชี Google เดียวกับที่ใช้เข้ากลุ่ม: <ลิงก์ opt-in ของ Play>
2. กด "Become a tester" แล้วกดลิงก์ไป Google Play เพื่อติดตั้ง
   (ถ้ายังหาไม่เจอ รอ 10–30 นาทีแล้วลองอีกครั้ง)
3. ห้ามกด "Leave the program" และห้ามถอนแอปภายใน 14 วันนะครับ ไม่อย่างนั้นการนับจะเริ่มใหม่

ตอนเปิดครั้งแรก
4. แอปจะขอสิทธิ์ทีละข้อ: การแจ้งเตือน, แสดงเต็มหน้าจอ, ปลุกตรงเวลา ให้กดอนุญาตทุกข้อ
   มือถือ Xiaomi / Redmi / POCO: ทำตามหน้า "Phone brand" ในแอปด้วย (แสดงบนหน้าจอล็อก, Autostart, แบตเตอรี่)
5. ลองกดปลุกทดสอบ แล้วรินจะพาทัวร์และให้ลองเล่นเกม (เมนู Settings → Try the games เล่นซ้ำได้)

ระหว่าง 14 วัน
6. ตั้งปลุกจริงสักสองสามเช้า ลองเลือกเกมต่างกัน แอปทั้งหมดเป็นภาษาอังกฤษ
7. ถ้าเจอปัญหา เช่น ปลุกไม่ดัง ดังช้า จอไม่ขึ้น หรือแอปค้าง ให้เปิดเมนูรูปคลื่นชีพจรบนหน้าแรก (Diagnostics)
   กด Copy report แล้วส่งมาให้ผม (ข้อความนี้ไม่มีข้อมูลส่วนตัว มีแค่รุ่นเครื่องกับเวลาที่ปลุก)
8. แอปอัปเดตผ่าน Google Play เอง หลังอัปเดต Xiaomi บางรุ่นจะปิดสิทธิ์ "แสดงเต็มหน้าจอ" เอง ถ้ามีแถบสีแดงขึ้นในแอป กดตามได้เลย

ฟอร์ม feedback: https://docs.google.com/forms/d/e/1FAIpQLSdn4FUQ24MgcMgdw-0XJ4olDpFBZ4kPMPz39Xns0tiDkjE3jQ/viewform (วันที่ 7 และวันที่ 14)
ความเป็นส่วนตัว: นาฬิกาปลุกและเกมทำงานออฟไลน์ทั้งหมด สิ่งเดียวที่ใช้อินเทอร์เน็ตคือกระดานคะแนนทัวร์นาเมนต์ และเฉพาะเมื่อคุณเปิดการโพสต์ https://earthkodyai.github.io/rin/privacy/th/
```

## Google Form (สร้างแล้ว 2026-10-04 ด้วยบัญชี earth3joy, เผยแพร่แล้ว: ใครมีลิงก์ก็ตอบได้ ไม่ต้องล็อกอิน ไม่เก็บอีเมล ตอบได้หลายครั้ง, ข้อ 1 บังคับ)

ชื่อ: "Rin: Anime Wake-up Alarm · feedback ผู้ทดสอบ" · ไม่เก็บอีเมล (เลือกไม่เก็บ) · ถามรอบละครั้ง

1. ตอบรอบไหน: วันที่ 7 / วันที่ 14 *(บังคับ)*
2. ยี่ห้อและรุ่นมือถือ *(ข้อความสั้น)*
3. ช่วงนี้ปลุกจริงไปกี่ครั้ง: 0 / 1–2 / 3–5 / 6 ขึ้นไป
4. มีครั้งไหนที่ปลุกไม่ดัง ดังช้า หรือหน้าจอรินไม่ขึ้นไหม: ไม่มี / มี (เล่าในข้อ 12)
5. เกมไหนที่เล่นแล้ว *(เลือกได้หลายข้อ)*: กดตามสี / สลับแก้ว / พูดตามริน / ยังไม่ได้เล่น
6. เกมช่วยให้ตื่นจริงไหม (1 = ไม่ช่วย, 5 = ช่วยมาก)
7. ตั้งระดับไหนบ่อยที่สุด: Easy / Normal / Hard / Nightmare
8. ระดับนั้นตอนเพิ่งตื่นเป็นยังไง: ง่ายไป / พอดี / ยากไป
9. ลองทัวร์นาเมนต์ไหม: ยังไม่ได้ลอง / ลองแล้ว ไม่ได้โพสต์ออนไลน์ / ลองแล้ว และโพสต์ขึ้นกระดานคะแนน
10. รินน่ารักหรือน่ารำคาญ (1 = น่ารำคาญ, 5 = น่ารัก)
11. จะใช้ต่อเป็นนาฬิกาปลุกหลักไหม: ใช้ / อาจจะ / ไม่ใช้
12. ปัญหาหรือบั๊กที่เจอ *(ข้อความยาว)*
13. อยากให้เพิ่มหรือแก้อะไร หรือเหตุผลที่จะไม่ใช้ต่อ *(ข้อความยาว)*
